# 実務に近い構成の架空資料

自治体の実証事業を想定した **創作の開発用資料** です。実在の行政機関、
デジタル庁の決定・調達・予算や個人情報を転載したものではありません。
実資料での精度や、未使用の評価集合に対する汎化性能は測っていません。

- `operations-review.md`: 責任分担表、千円単位の予算表、参考見積、旧版の
  履歴、未承認の将来移管を含む進行管理メモ。正解の関係は10件。
- `procurement-ledger.csv`: 年度・対象範囲つき台帳。千円単位の予算と円単位の
  見積、承認済みの0、支援担当の空欄、未定の承認担当を区別する。正解は7件。
- `ontology.json`: 主担当・支援担当・承認担当・承認済予算の4述語。
- `gold.json`: モデル呼び出し前に定義した17件の正解と、各行が保持すべき
  原文の行番号。**抽出リクエストには送らない**。正解・評価規則は比較中に変更しない。

金額のオブジェクトは原文セルの文字列です。たとえば `4,800` に `千円` を
合成して付加せず、単位を示すヘッダーを根拠に含めます。数値だけを円として
下流DBへ格納せず、`evidence_json` と一緒に扱ってください。

空欄は「未記載」なので関係を作りません。「未定」は `unknown`、列挙された
未決定の候補や未承認の条件付き移管は `ambiguous` とします。同じ関係の反復は
同一の時点・範囲なら根拠をまとめ、時点の異なる履歴は分けます。

`scripts/probe_relation_evidence.py` は保存済みの元ファイル・抽出束を検証し、
値の一致、関係タプルの一致、必要な根拠の保持を別々に採点します。
テキスト値が合っても列や主語を取り違えれば関係の一致にはなりません。
必要根拠の採点はこの固定資料の行番号によるもので、一般的な意味検証器ではありません。
